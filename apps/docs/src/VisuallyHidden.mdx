# VisuallyHidden

VisuallyHidden hides content from sight while keeping it available to screen
readers and other assistive technology. Reach for it when meaning is conveyed
visually (an icon, a layout, color) but a text equivalent still needs to be
announced.

Unlike `display: none` or the `hidden` attribute — which remove content from the
accessibility tree entirely — VisuallyHidden uses the well-tested "sr-only"
clipping technique so the text stays in the tree and is read aloud.

Common uses:

- A text label inside an icon-only button
- A `role="status"`/`role="alert"` live region for screen-reader-only updates
- Extra context for links ("Read more **about pricing**")
- A "skip to content" link that appears on keyboard focus (`focusable`)

Render any element with `as`, and pass `focusable` to reveal the content when it
(or a descendant) receives keyboard focus.
