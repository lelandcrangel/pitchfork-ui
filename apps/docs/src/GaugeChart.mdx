# Gauge Chart

A radial progress chart for displaying a single value as a proportion of a maximum. Use it in dashboards, metric cards, and KPI summaries alongside a number.

The filled arc is announced as a `meter` landmark so screen readers communicate the current value and range without relying on the visual.
