# Notifications

Notification and NotificationStack provide toast-style status messages with optional actions and dismiss controls.

## Structure

**`Notification`** — a single message: a variant icon, `heading`, `description`,
optional `action`, and a dismiss button (`dismissible`). Render it inline on its
own, or inside a stack.

**`NotificationStack`** — a fixed-position container that pins notifications to a
screen corner via `placement` (`top-right` by default) and stacks multiple
messages.

```tsx
<NotificationStack placement="top-right">
  <Notification
    variant="success"
    heading="Saved"
    description="Your changes are live."
    dismissible
  />
</NotificationStack>
```

For firing notifications imperatively from anywhere (without managing the list
yourself), see the [`Toast`](?path=/docs/components-toast--docs) API, which builds
on these primitives.

## Variants

The `variant` prop sets the icon, color, and announcement urgency:

**`info`** — neutral, non-critical updates. Announced politely (`role="status"`).

**`success`** — confirms an action completed. Announced politely (`role="status"`).

**`warning`** — something needs attention but isn't blocking. Announced assertively
(`role="alert"`).

**`danger`** — an error or failure requiring immediate attention. Announced
assertively (`role="alert"`).
