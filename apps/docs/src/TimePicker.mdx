# TimePicker

TimePicker selects a time of day from scrollable hour and minute columns (plus an
AM/PM column in 12-hour mode). It pairs naturally with `DatePicker` to complete a
date-and-time form.

The value is always a canonical 24-hour string — `"HH:mm"` (e.g. `"14:30"`) — so
it's easy to store and compare regardless of the display format. Pass
`hourCycle={12}` to display 12-hour time with AM/PM, and `minuteStep` to coarsen
the minutes column (e.g. `15` for quarter-hour increments).

The panel is portaled and follows the ARIA `dialog` pattern; each column is a
listbox, and arrow keys move through options within a focused column.

## API Reference

### `TimePicker`

**`onValueChange`** — `(value: string) => void`  
Called with a canonical 24-hour string `"HH:mm"` (e.g. `"14:30"`) when the user confirms a time. The value format is always 24-hour regardless of the `hourCycle` display setting.

**`value`** — `string`  
The currently selected time in controlled mode (`"HH:mm"`). Pass `""` for an empty state. Pair with `onValueChange`.

**`defaultValue`** — `string`  
The initially selected time in uncontrolled mode.

**`hourCycle`** — `12 | 24` · default `24`  
Display format. `12` shows a 12-hour clock with an AM/PM column; `24` shows a 24-hour clock. The emitted value is always canonical 24-hour either way.

**`minuteStep`** — `number` · default `1`  
Granularity of the minutes column. `15` gives quarter-hour increments; `30` gives half-hour. Must divide evenly into 60.

**`placeholder`** — `string`  
Text shown in the trigger when no time is selected.

**`name`** — `string`  
Forwarded to the hidden `<input>` used for form submission.

**`label`** — `string`  
Visible label rendered above the trigger.

**`description`** — `string`  
Helper text rendered below the label.

**`error`** — `string`  
Error message rendered below the trigger. Also sets `aria-invalid` on the trigger.

**`required`** — `boolean`  
Marks the field as required and sets `aria-required` on the trigger.

**`disabled`** — `boolean`  
Disables the trigger and prevents opening the time panel.
