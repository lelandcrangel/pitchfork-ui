# Popover

A floating, anchored container for rich content — info panels, small forms, or option groups — toggled from a trigger element. Unlike `Tooltip` (text on hover) or `Dropdown` (a menu of actions), a Popover holds arbitrary interactive content.

Pass any element as the `trigger`; the Popover augments it with `aria-haspopup="dialog"` / `aria-expanded` and anchors the panel to it (flipping above when there's no room below). The panel opens/closes with an animation, moves focus into itself on open and returns focus to the trigger on close, and dismisses on outside click or Escape. It's controllable via `open` / `onOpenChange`.

## API Reference

### `Popover`

**`trigger`** — `ReactElement` · required  
The element that toggles the popover. It is cloned and augmented with `onClick`, `aria-haspopup="dialog"`, `aria-expanded`, and `aria-controls` — so it must accept and forward a `ref`. A `<Button>` or any focusable element works out of the box.

**`children`** — `ReactNode` · required  
The content rendered inside the popover panel.

**`onOpenChange`** — `(open: boolean) => void`  
Called when the popover opens or closes.

**`open`** — `boolean`  
Controlled open state. Pair with `onOpenChange`.

**`defaultOpen`** — `boolean`  
Initial open state in uncontrolled mode.

**`align`** — `'start' | 'end'` · default `'start'`  
Horizontal alignment of the panel relative to the trigger. `'end'` right-aligns the panel.

**`label`** — `string`  
Accessible label for the popover dialog (`aria-label`). Provide this when the panel content has no visible heading.

**`closeOnOutsideClick`** — `boolean` · default `true`  
Whether clicking outside the panel closes it.
