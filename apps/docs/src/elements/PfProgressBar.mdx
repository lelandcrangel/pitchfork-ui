# `<pf-progress-bar>`


A horizontal determinate progress track.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `label` | `label` | `string \| undefined` | — | Accessible name. |
| `max` | `max` | `number` | `100` | The top of the scale. |
| `showValue` | `show-value` | `boolean` | `true` | Show the percentage beside the track. Reflected for the stylesheet. |
| `value` | `value` | `number` | `0` | How far along, on the 0..max scale. |

## Shadow parts

| Part | Description |
| --- | --- |
| `fill` | the filled portion. |
| `track` | the unfilled groove. |
| `value` | the percentage readout. |
