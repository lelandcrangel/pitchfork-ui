# `<pf-progress-steps>`


A step indicator over `pf-progress-step` children.

The group owns everything a step cannot see on its own: its number, whether
it is last — so only the others draw a connector — the orientation, and the
status inference, which depends on where the current step is.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `orientation` | `orientation` | `"horizontal" \| "vertical"` | `'horizontal'` | Layout. Reflected, and pushed down onto every step. |

## Methods

| Method | Signature | Description |
| --- | --- | --- |
| `refresh()` | `refresh() =&gt; Promise&lt;void&gt;` | Re-reads the children, for a consumer who set a step's status through its *property* — which leaves no attribute and fires no `slotchange`. |

## Slots

| Slot | Description |
| --- | --- |
| _(default)_ | the `pf-progress-step` children. |
