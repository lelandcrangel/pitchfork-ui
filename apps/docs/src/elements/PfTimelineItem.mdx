# `<pf-timeline-item>`


One entry in a `pf-timeline`.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `last` | `last` | `boolean` | `false` | Set by the group: the last entry has no connector and no space below. |
| `tone` | `tone` | `"danger" \| "default" \| "success" \| "warning"` | `'default'` | Marker colour. Reflected so the stylesheet can select on it. |

## Slots

| Slot | Description |
| --- | --- |
| `description` | secondary text below the title. |
| `icon` | an icon inside the marker, in place of the plain dot. |
| `timestamp` | short meta text beside the title. |
| `title` | the entry's title. |

## Shadow parts

| Part | Description |
| --- | --- |
| `connector` | the line down to the next entry. Absent on the last. |
| `content` | the box holding title, timestamp and description. |
| `header` | the row holding the title and the timestamp. |
| `marker` | the dot, or the circle around a slotted icon. |
| `rail` | the column holding the marker and the connector. |
| `title` | the title's box. |
