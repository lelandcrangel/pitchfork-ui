# `<pf-utility-button>`


A compact button for toolbars and table rows, where the affordance is often
an icon alone.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `disabled` | `disabled` | `boolean` | `false` | Disable the button. Reflected so the stylesheet can select on it. |
| `label` | `label` | `string \| undefined` | — | Accessible name. Required for an icon-only button, and also used as the native tooltip unless `tooltip` says otherwise. |
| `size` | `size` | `"md" \| "sm"` | `'md'` | Control size. Reflected so the stylesheet can select on it. |
| `tooltip` | `tooltip` | `string \| undefined` | — | Native tooltip text. Defaults to `label`. |
| `type` | `type` | `"button" \| "reset" \| "submit"` | `'button'` | Mirrors the native attribute. |
| `variant` | `variant` | `"brand" \| "destructive" \| "neutral"` | `'neutral'` | Colour treatment. Reflected so the stylesheet can select on it. |

## Slots

| Slot | Description |
| --- | --- |
| _(default)_ | the button's label. Omit it for an icon-only button, and give a `label` so the button still has an accessible name. |
| `icon` | a leading icon, usually `pf-icon`. |
