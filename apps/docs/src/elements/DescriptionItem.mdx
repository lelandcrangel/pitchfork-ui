# `<pf-description-item>`


One term and its details, inside a `pf-description-list`.

Renders a `<dt>` and a `<dd>`. The term is the `term` slot, or the `term`
attribute for plain text; the details are the default slot.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `divided` | `divided` | `boolean` | `false` | Set by the list: draw a rule above this item. Reflected for the stylesheet. |
| `orientation` | `orientation` | `"horizontal" \| "vertical"` | `'horizontal'` | Set by the list. Reflected for the stylesheet. |
| `term` | `term` | `string \| undefined` | — | The term, as text. A `term` slot wins over it. |

## Slots

| Slot | Description |
| --- | --- |
| _(default)_ | the details. |
| `term` | the term, when it needs markup. |

## Shadow parts

| Part | Description |
| --- | --- |
| `details` | the `<dd>`. |
| `term` | the `<dt>`. |
