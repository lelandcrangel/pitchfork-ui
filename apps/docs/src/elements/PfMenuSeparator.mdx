# `<pf-menu-separator>`


A rule between groups of menu items.

Unlike `pf-toolbar-separator` this needs no orientation: a menu is always a
column, so the rule is always horizontal.

## Usage

```html
<!-- Plain HTML, after `import '@pitchfork-ui/elements/loader'` -->
<pf-menu-separator></pf-menu-separator>
```

```tsx
// React, through the generated bindings
import { PfMenuSeparator } from '@pitchfork-ui/elements-react';

<PfMenuSeparator />;
```

```html
<!-- Angular, through the generated standalone components -->
<pf-menu-separator></pf-menu-separator>
```
