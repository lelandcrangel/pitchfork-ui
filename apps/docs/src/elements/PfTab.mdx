# `<pf-tab>`


One tab inside a `pf-tabs`.

It only reports that it was chosen; the group owns the selection, the single
tab stop and the id wiring — the same division as `pf-radio-group` with its
radios and `pf-select` with its options. The group writes `selected`,
`variant`, `size` and `full-width` back onto it, so the stylesheet has
reflected attributes to select on without the tab knowing anything about its
container.

The host is the `tab` itself rather than a wrapper around a button, so it is
the element the group focuses and the one `aria-controls` points from.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `badgePlacement` | `badge-placement` | `"end" \| "start"` | `'end'` | Which side of the label the count badge sits on. |
| `count` | `count` | `number \| undefined` | — | A count rendered as a badge beside the label (GitHub-style, "Issues 12"). It is left in the tab's accessible name, so a screen reader announces it. `0` shows a zero; omitting the prop shows no badge at all. |
| `disabled` | `disabled` | `boolean` | `false` | Reflected; the stylesheet and the group's own filtering both read it. |
| `fullWidth` | `full-width` | `boolean` | `false` | Set by the group from its own `fullWidth`. Reflected for the stylesheet. |
| `icon` | `icon` | `string \| undefined` | — | A decorative icon's name, from the same registry as `pf-icon`. |
| `iconPlacement` | `icon-placement` | `"end" \| "start"` | `'start'` | Which side of the label the icon sits on. |
| `selected` | `selected` | `boolean` | `false` | Set by the group. Reflected, so the stylesheet can mark the tab. |
| `size` | `size` | `"md" \| "sm"` | `'md'` | Set by the group from its own `size`. Reflected for the stylesheet. |
| `value` | `value` | `string` | `''` | Identifies the tab, and pairs it with the `pf-tab-panel` carrying the same value. | `variant` | `variant` | `"pills" \| "underline"` | `'underline'` | Set by the group from its own `variant`. Reflected for the stylesheet. |
