# `<pf-button>`


A button, with the variants, sizes and loading state the React `Button` has.

The first element in this package, and the one the whole pipeline was proved
on: the PostCSS chain, the generated React bindings and the generated Angular
component all exist because this built end to end before anything else was
attempted. `delegatesFocus` is why focusing the host reaches the real button
inside, which is what lets `pf-toolbar` treat it as an item.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `disabled` | `disabled` | `boolean` | `false` | Disable the button. |
| `fullWidth` | `full-width` | `boolean` | `false` | Stretch to the width of the container. |
| `label` | `label` | `string \| undefined` | — | Accessible name, for when the slot holds only an icon. |
| `loading` | `loading` | `boolean` | `false` | Show a spinner and block interaction. |
| `size` | `size` | `"lg" \| "md" \| "sm"` | `'md'` | Control size. Reflected so the stylesheet can select on it. |
| `type` | `type` | `"button" \| "reset" \| "submit"` | `'button'` | Mirrors the native attribute. `submit` and `reset` do not yet act on a form outside this element's shadow root -- that needs ElementInternals, which arrives with the form controls in Wave 3. |
| `variant` | `variant` | `"destructive" \| "ghost" \| "primary" \| "secondary"` | `'primary'` | Visual style. Reflected so the stylesheet can select on it. |
