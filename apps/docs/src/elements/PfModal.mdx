# `<pf-modal>`


A modal dialog.

A native `<dialog>` opened with `showModal()`, which from inside a shadow
root gives the focus trap, Escape and the backdrop for nothing — all
measured: focus moves inside on open and cannot be taken by a light-DOM
button, and a real Escape fires `cancel` then `close`. So `trapFocus` from
core is not needed here, unlike in the React component.

What `showModal()` does *not* do is lock page scroll — measured: a real
wheel still scrolled the page behind an open modal — so this element locks
it, exactly as the React component does.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `dismissable` | `dismissable` | `boolean` | `true` | Close on Escape or a click on the overlay. Defaults to true. |
| `label` | `label` | `string \| undefined` | — | Accessible name. Falls back to the text of whatever is slotted, which is usually the header — `aria-labelledby` cannot be used, because an IDREF does not cross a shadow boundary and the header is in the light DOM. |
| `open` | `open` | `boolean` | `false` | Whether the modal is showing. Reflected so the stylesheet can select on it. |
| `showCloseButton` | `show-close-button` | `boolean` | `true` | Render the corner close button. Defaults to true. |
| `size` | `size` | `"lg" \| "md" \| "sm"` | `'md'` | Panel width. Reflected so the stylesheet can select on it. |

## Events

| Event | Detail | Description |
| --- | --- | --- |
| `pfOpenChange` | `\{ open: boolean; \}` | Fires whenever the modal opens or closes, whoever caused it. |

## Methods

| Method | Signature | Description |
| --- | --- | --- |
| `hide()` | `hide() =&gt; Promise&lt;void&gt;` | Closes the modal. |
| `show()` | `show() =&gt; Promise&lt;void&gt;` | Opens the modal. |

## Slots

| Slot | Description |
| --- | --- |
| _(default)_ | the modal's sections, usually `pf-modal-header`, `pf-modal-body` and `pf-modal-footer`. |

## Shadow parts

| Part | Description |
| --- | --- |
| `close` | the close button. |
| `dialog` | the native dialog, which is also the overlay. |
| `panel` | the bordered box the content sits in. |
