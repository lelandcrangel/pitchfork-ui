# `<pf-card-footer>`


The bottom section of a `pf-card`, separated from what precedes it by a rule.
Lays its children out in a row, which is what makes it the natural home for
a card's actions.

## Slots

| Slot | Description |
| --- | --- |
| _(default)_ | the footer's content, usually buttons. |

## Usage

```html
<!-- Plain HTML, after `import '@pitchfork-ui/elements/loader'` -->
<pf-card-footer></pf-card-footer>
```

```tsx
// React, through the generated bindings
import { PfCardFooter } from '@pitchfork-ui/elements-react';
```
