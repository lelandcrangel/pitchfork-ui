# `<pf-scroll-area>`


A scrollable region with a styled, non-overlaying scrollbar.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `focusable` | `focusable` | `boolean` | `true` | Make the region keyboard-focusable so it can be scrolled with the arrow keys (WCAG 2.1.1). Set false when a focusable child already provides keyboard access. |
| `orientation` | `orientation` | `"both" \| "horizontal" \| "vertical"` | `'vertical'` | Which axis scrolls. Reflected so the stylesheet can select on it. |

## Slots

| Slot | Description |
| --- | --- |
| _(default)_ | the content to scroll. |
