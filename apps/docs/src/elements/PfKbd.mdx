# `<pf-kbd>`


A keyboard key or a combination of them, as `<kbd>` elements.

`keys` renders one cap per entry with separators between; a single key can
be slotted instead.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `keys` | — | `string[] \| undefined` | — | A key combination rendered as one cap, e.g. `["⌘", "K"]`. |
| `separator` | `separator` | `string` | `'+'` | Separator between keys in a combination. Defaults to `+`. |
| `size` | `size` | `"md" \| "sm"` | `'md'` | — |

## Slots

| Slot | Description |
| --- | --- |
| _(default)_ | a single key, when `keys` is not given. |

## Shadow parts

| Part | Description |
| --- | --- |
| `kbd` | the native kbd element. |
