# `<pf-notification>`


A notification: an icon, a heading, a body and an optional dismiss button.

The role comes from core's `liveRegionRole`, so `warning` and `danger`
announce assertively and `info` and `success` wait their turn. The React
component used to be `role="status"` for all four — the rule lived in
`Alert` and nowhere else — which is why the mapping is now shared.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `description` | `description` | `string \| undefined` | — | The body, when nothing is slotted. |
| `dismissable` | `dismissable` | `boolean` | `false` | Render the dismiss button. |
| `exiting` | `exiting` | `boolean` | `false` | Set while the exit animation plays. Reflected for the stylesheet. |
| `heading` | `heading` | `string \| undefined` | — | The bold first line. |
| `variant` | `variant` | `"danger" \| "info" \| "success" \| "warning"` | `'info'` | Severity. Reflected, because the stylesheet selects on it. |

## Events

| Event | Detail | Description |
| --- | --- | --- |
| `pfDismiss` | `void` | Fires once the notification has finished leaving, which is the point at which its owner should remove it from the DOM. |

## Methods

| Method | Signature | Description |
| --- | --- | --- |
| `dismiss()` | `dismiss() =&gt; Promise&lt;void&gt;` | Starts the exit animation and resolves when it has finished, having emitted `pfDismiss`. Calling it twice is harmless. |

## Slots

| Slot | Description |
| --- | --- |
| _(default)_ | the body, used instead of the `description` prop when present. |
| `action` | buttons or links under the body. |
| `icon` | replaces the icon the variant would choose. |

## Shadow parts

| Part | Description |

| `title` | the heading. |
