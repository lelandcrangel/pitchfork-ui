# `<pf-progress-circle>`


A circular determinate progress track.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `label` | `label` | `string \| undefined` | — | Accessible name. |
| `max` | `max` | `number` | `100` | The top of the scale. |
| `showValue` | `show-value` | `boolean` | `true` | Show the percentage in the middle. Reflected for the stylesheet. |
| `size` | `size` | `number` | `64` | Diameter in pixels. |
| `strokeWidth` | `stroke-width` | `number` | `6` | Ring thickness in pixels. |
| `value` | `value` | `number` | `0` | How far along, on the 0..max scale. |
