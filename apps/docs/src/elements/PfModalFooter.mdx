# `<pf-modal-footer>`


The footer section of a `pf-modal`.

A separate element rather than a named slot, for the reason `pf-card` gives:
a named slot would need emptiness detection or leave a padded, bordered
strip when nothing was slotted into it.

## Slots

| Slot | Description |
| --- | --- |
| _(default)_ | the section's content. |

## Usage

```html
<!-- Plain HTML, after `import '@pitchfork-ui/elements/loader'` -->
<pf-modal-footer></pf-modal-footer>
```

```tsx
// React, through the generated bindings
import { PfModalFooter } from '@pitchfork-ui/elements-react';

<PfModalFooter />;
```

