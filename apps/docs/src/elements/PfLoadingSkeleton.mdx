# `<pf-loading-skeleton>`


A shimmering placeholder for content that has not arrived.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `height` | `height` | `number \| string` | `16` | Height, as a CSS length. A bare number is read as pixels. |
| `label` | `label` | `string` | `'Loading content'` | Accessible name, announced by the live region. |
| `rounded` | `rounded` | `boolean` | `false` | Use a pill radius instead of the default. Reflected for the stylesheet. |
| `width` | `width` | `number \| string` | `'100%'` | Width, as a CSS length. A bare number is read as pixels. |

## Shadow parts

| Part | Description |
| --- | --- |
| `label` | the visually hidden text the live region announces. |

## Usage
