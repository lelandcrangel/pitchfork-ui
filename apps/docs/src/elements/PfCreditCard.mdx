# `<pf-credit-card>`


A card-shaped display of payment details. Presentational only — it stores
nothing and submits nothing.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `brand` | `brand` | `"amex" \| "generic" \| "mastercard" \| "visa"` | `'generic'` | Card network. Reflected so the stylesheet can pick the gradient. |
| `cardNumber` | `card-number` | `string` | `''` | The number to display. Separators in the input are regrouped. |
| `cardholderName` | `cardholder-name` | `string` | `''` | Name on the card. |
| `cvc` | `cvc` | `string \| undefined` | — | Security code. Omit it to leave the field out entirely. |
| `expiry` | `expiry` | `string` | `''` | Expiry, displayed as given. |
| `masked` | `masked` | `boolean` | `true` | Hide all but the last four digits, and the CVC with it. Defaults to true, so the careless case is the safe one. Reflected for the stylesheet. |

## Shadow parts

| Part | Description |
| --- | --- |
