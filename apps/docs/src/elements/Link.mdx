# `<pf-link>`


A text link, in the library's colours and focus ring.

For a link that has to look like a button — "Go to settings" as a call to
action — use `pf-button` with `href` instead. This is the one that sits in
running text.

`external` is the one decision it makes for you. A link that opens a new tab
should say so before it is followed, so it gets `target="_blank"`, a
`rel` of `noopener noreferrer` unless you give one, the `external` icon
role, and "(opens in a new tab)" for a screen reader — which an icon alone
would not tell anyone.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `download` | `download` | `string \| undefined` | — | Download the target instead of navigating, as on an `<a>`. |
| `external` | `external` | `boolean` | `false` | Opens in a new tab, and says so. |
| `href` | `href` | `string \| undefined` | — | Where the link goes. |
| `rel` | `rel` | `string \| undefined` | — | The link's relationship to its target, as on an `<a>`. |
| `target` | `target` | `string \| undefined` | — | Where it opens, as on an `<a>`. `external` sets `_blank`. |
| `variant` | `variant` | `"default" \| "subtle"` | `'default'` | `subtle` draws the link in the surrounding text colour, underlined, for a page dense with links. Reflected for the stylesheet. |
