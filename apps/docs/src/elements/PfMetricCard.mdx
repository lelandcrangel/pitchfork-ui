# `<pf-metric-card>`


One figure worth looking at: a heading, the number, and optionally how it
has moved.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `icon` | `icon` | `string \| undefined` | — | An icon name from the same registry as `pf-icon`. |
| `trend` | `trend` | `"negative" \| "neutral" \| "positive"` | `'neutral'` | Which way the trend reads. Reflected so the stylesheet can colour it. |

## Slots

| Slot | Description |
| --- | --- |
| _(default)_ | the number. |
| `action` | a control in the card's top corner. |
| `description` | a line below the number. |
| `heading` | what the number is. |
| `icon` | a small icon beside the heading. |
| `trend` | how it has moved, shown as a pill beside the number. |

## Shadow parts

| Part | Description |
| --- | --- |
| `action` | the box holding the action slot. |
| `body` | the row holding the number and the trend. |
| `header` | the row holding the heading and the action. |
| `heading` | the heading's box. |
| `icon` | the icon's box. |
| `trend` | the trend pill. |
| `value` | the number's box. |
