# DateRangePicker

DateRangePicker lets users select a continuous date range — a start date and an
end date — from a two-month calendar view. On desktop the two months appear
side-by-side; on mobile they stack with independent navigation.

**Selection flow:** clicking once sets the start date; clicking again sets the
end date and closes the popover. The in-between days are highlighted as the user
hovers. Clicking the same day twice resets to a new start.

The calendar portal avoids overflow clipping and follows the ARIA `dialog`
pattern. The field supports `label`, `description`, and `error` through
FieldWrapper, and emits `onValueChange(range)` where `range.start`/`range.end`
are `Date | null`.
