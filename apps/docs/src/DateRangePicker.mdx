# DateRangePicker

DateRangePicker lets users select a continuous date range — a start date and an
end date — from a two-month calendar view. On desktop the two months appear
side-by-side; on mobile they stack with independent navigation.

**Selection flow:** clicking once sets the start date; clicking again sets the
end date and closes the popover. The in-between days are highlighted as the user
hovers. Clicking the same day twice resets to a new start.

The calendar portal avoids overflow clipping and follows the ARIA `dialog`
pattern. The field supports `label`, `description`, and `error` through
FieldWrapper, and emits `onValueChange(range)` where `range.start`/`range.end`
are `Date | null`.

## API Reference

### `DateRangePicker`

**`onValueChange`** — `(range: DateRange) => void`  
Called after the user completes a two-click selection. Receives `{ start: Date, end: Date }` with both dates normalized to noon local time. If the user clicks the same day twice the selection resets and `end` will be `null`.

**`value`** — `DateRange`  
The currently selected range in controlled mode. Pair with `onValueChange`.

**`defaultValue`** — `DateRange`  
The initially selected range in uncontrolled mode.

**`startPlaceholder`** — `string` · default `'Start date'`  
Placeholder text for the start date slot in the trigger.

**`endPlaceholder`** — `string` · default `'End date'`  
Placeholder text for the end date slot in the trigger.

**`disabledDates`** — `(date: Date) => boolean`  
Called for each visible day. Return `true` to disable that day.

**`showOutsideDays`** — `boolean` · default `true`  
Shows days from adjacent months that fill out the calendar grid.

**`startYear`** — `number`  
The earliest year accessible via the year selector. Defaults to 50 years before today.

**`endYear`** — `number`  
The latest year accessible via the year selector. Defaults to 50 years after today.

**`label`** — `string`  
Visible label rendered above the trigger.

**`description`** — `string`  
Helper text rendered below the label.

**`error`** — `string`  
Error message rendered below the trigger. Also sets `aria-invalid` on the trigger.

**`required`** — `boolean`  
Marks the field as required and sets `aria-required` on the trigger.

**`disabled`** — `boolean`  
Disables the trigger and prevents opening the calendar.

---

### `DateRange`

**`start`** — `Date | null` · required  
The start of the selected range, or `null` when unset.

**`end`** — `Date | null` · required  
The end of the selected range, or `null` when only a start date has been chosen.
