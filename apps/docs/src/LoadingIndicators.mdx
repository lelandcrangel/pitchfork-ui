# Loading Indicators

Loading indicators communicate in-progress states for asynchronous actions and content fetching.

## Variants

Three separate components — pick the one that fits the context:

**`LoadingSpinner`** — a circular spinner for short, indeterminate waits (button
actions, inline loads).

**`LoadingDots`** — a compact animated dot sequence for tight spaces like buttons
or inline text.

**`LoadingSkeleton`** — placeholder blocks that mimic the shape of content while
it loads, reducing layout shift on initial page or section fetches.
