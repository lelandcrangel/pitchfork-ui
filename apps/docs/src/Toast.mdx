# Toast

An imperative toast API built on top of `Notification`. Mount `<ToastProvider>` once at your app root, then fire toasts from anywhere — inside a component via `useToast()`, or from outside React entirely via the standalone `toast()` helper.

---

## Setup

Wrap your app root with `<ToastProvider>` once. This is all that's needed — it portals the notification stack to `document.body` automatically.

```tsx
import { ToastProvider } from '@pitchfork-ui/react';

function App() {
  return (
    <ToastProvider>
      <YourApp />
    </ToastProvider>
  );
}
```

---

## Usage

### Inside a component — `useToast()`

```tsx
import { useToast } from '@pitchfork-ui/react';

function SaveButton() {
  const { toast } = useToast();

  return <Button onClick={() => toast({ heading: 'Saved', variant: 'success' })}>Save</Button>;
}
```

### Outside a component — `toast()`

Works in event handlers, `async` callbacks, API response handlers, and anywhere else outside the React tree.

```tsx
import { toast } from '@pitchfork-ui/react';

async function saveData() {
  await api.save();
  toast.success({ heading: 'Saved', description: 'Your changes were saved.' });
}
```

## API Reference

### `<ToastProvider>`

| Prop              | Type                                                           | Default       | Description                                             |
| ----------------- | -------------------------------------------------------------- | ------------- | ------------------------------------------------------- |
| `placement`       | `'top-right' \| 'top-left' \| 'bottom-right' \| 'bottom-left'` | `'top-right'` | Screen position of the toast stack                      |
| `defaultDuration` | `number \| false`                                              | `4000`        | Auto-dismiss delay in ms; `false` disables auto-dismiss |

### `useToast()`

Returns an object with three methods:

| Method       | Signature                           | Description                            |
| ------------ | ----------------------------------- | -------------------------------------- |
| `toast`      | `(options: ToastOptions) => string` | Fire a toast; returns its `id`         |
| `dismiss`    | `(id: string) => void`              | Immediately dismiss a specific toast   |
| `dismissAll` | `() => void`                        | Immediately dismiss all visible toasts |

### `toast()` convenience variants

The standalone `toast()` helper also exposes shorthand methods that pre-set the variant:

```ts
toast.info({ heading: 'Heads up' });
toast.success({ heading: 'Done' });
toast.warning({ heading: 'Watch out' });
toast.danger({ heading: 'Error' });
```

### `ToastOptions`

| Prop          | Type                                           | Default          | Description                               |
| ------------- | ---------------------------------------------- | ---------------- | ----------------------------------------- |
| `variant`     | `'info' \| 'success' \| 'warning' \| 'danger'` | `'info'`         | Visual style and icon                     |
| `heading`     | `ReactNode`                                    | —                | Bold title line                           |
| `description` | `ReactNode`                                    | —                | Supporting detail below the heading       |
| `action`      | `ReactNode`                                    | —                | Optional action (e.g. an undo button)     |
| `duration`    | `number \| false`                              | provider default | Override auto-dismiss for this toast only |
| `dismissible` | `boolean`                                      | `true`           | Show the × close button                   |
