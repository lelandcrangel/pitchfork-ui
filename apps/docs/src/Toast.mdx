# Toast

An imperative toast API built on top of `Notification`. Mount `<ToastProvider>` once at your app root, then fire toasts from anywhere — inside a component via `useToast()`, or from outside React entirely via the standalone `toast()` helper.

---

## Setup

Wrap your app root with `<ToastProvider>` once. This is all that's needed — it portals the notification stack to `document.body` automatically.

```tsx
import { ToastProvider } from '@pitchfork-ui/react';

function App() {
  return (
    <ToastProvider>
      <YourApp />
    </ToastProvider>
  );
}
```

---

## Usage

### Inside a component — `useToast()`

```tsx
import { useToast } from '@pitchfork-ui/react';

function SaveButton() {
  const { toast } = useToast();

  return <Button onClick={() => toast({ heading: 'Saved', variant: 'success' })}>Save</Button>;
}
```

### Outside a component — `toast()`

Works in event handlers, `async` callbacks, API response handlers, and anywhere else outside the React tree.

```tsx
import { toast } from '@pitchfork-ui/react';

async function saveData() {
  await api.save();
  toast.success({ heading: 'Saved', description: 'Your changes were saved.' });
}
```

## API Reference

### `<ToastProvider>`

Place this once at your app root. All props are optional.

**`placement`** — `'top-right' | 'top-left' | 'bottom-right' | 'bottom-left'` · default `'top-right'`
Where the toast stack appears on screen.

**`defaultDuration`** — `number | false` · default `4000`
Auto-dismiss delay in milliseconds for all toasts. Pass `false` to keep toasts on screen until the user manually dismisses them.

---

### `useToast()`

```ts
const { toast, dismiss, dismissAll } = useToast();
```

**`toast(options)`** — fires a toast and returns its `id` string.

**`dismiss(id)`** — immediately starts the exit animation for a specific toast.

**`dismissAll()`** — immediately starts the exit animation for all visible toasts.

---

### `toast()` standalone helper

The named export `toast` works identically to the hook's `toast` method but can be called anywhere — outside components, in `async` functions, route handlers, etc. It also exposes variant shorthands:

```ts
toast({ heading: 'Custom', variant: 'info' });

toast.info({ heading: 'Heads up' });
toast.success({ heading: 'Saved' });
toast.warning({ heading: 'Watch out' });
toast.danger({ heading: 'Error occurred' });
```

---

### `ToastOptions`

**`variant`** — `'info' | 'success' | 'warning' | 'danger'` · default `'info'`
Controls the icon and colour.

**`heading`** — `ReactNode`
The bold primary line of the toast.

**`description`** — `ReactNode`
Supporting detail shown below the heading.

**`action`** — `ReactNode`
Optional inline action, e.g. an Undo button.

**`duration`** — `number | false`
Overrides `defaultDuration` for this toast only. Pass `false` to make it persistent.

**`dismissible`** — `boolean` · default `true`
Whether to show the × close button.
