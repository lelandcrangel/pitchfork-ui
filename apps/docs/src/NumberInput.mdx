# NumberInput

NumberInput is a numeric field with decrement/increment steppers, `min`/`max`/`step`
bounds, and optional locale-aware formatting. It follows the ARIA `spinbutton`
pattern — `aria-valuemin`/`aria-valuemax`/`aria-valuenow` are wired automatically,
and `ArrowUp`/`ArrowDown` (plus `Home`/`End`) adjust the value from the keyboard.
