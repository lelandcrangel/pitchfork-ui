# Sparkline

A compact inline chart for showing trends at a glance. Designed to live inside table cells, metric cards, and dashboards alongside a number — no axes, no labels, just the shape of the data.

## Examples

### Line

The default `variant="line"` — a plain trend line. Best for dense, side-by-side
comparisons like table rows where many sparklines sit together.

<Canvas of={SparklineExamples.Line} meta={SparklineExamples} />

### Area fill

`variant="area"` adds a soft fill beneath the line for more visual weight — best
when a single trend is the focus, such as a metric card.
