# Heatmap

A calendar heatmap for visualizing daily activity over time — the GitHub contribution graph pattern. Days are laid out as a grid of weeks (columns) and weekdays (rows), with cell color intensity scaled to each day's value.

Pass an array of `{ date, value }` where `date` is an ISO `YYYY-MM-DD` string. The color ramp is derived from `--pf-heatmap-color` via `color-mix`, so it follows your theme and works in dark mode automatically.
