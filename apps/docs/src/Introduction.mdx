## Get started

Install the package:

```bash
npm install @pitchfork-ui/react
```

Import the stylesheet once at your app's entry point, then use components anywhere:

```tsx
import '@pitchfork-ui/react/styles.css';
import { Button } from '@pitchfork-ui/react';

export function Example() {
  return <Button variant="primary">Get started</Button>;
}
```

The stylesheet bundles the design tokens, so there's no separate theme package to
install. Components are tree-shakeable and ship with `"use client"` directives,
so they work in React Server Component frameworks like Next.js App Router.

## Explore the docs

- **Foundations** — design tokens, color, typography, theming, and dark mode.
- **Components** — the full library, each with an interactive playground and a “Show code” panel.
- **Patterns** — complete compositions like login, settings, pricing, and checkout.
- **Changelog** — release history, generated from the published package.

Use the **theme toggle** on interactive stories to preview any component in light or
dark mode, and the **CSS Variables** panel to experiment with token overrides live.
