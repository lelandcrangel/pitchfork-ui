# PitchforkUI

PitchforkUI is a React-based design system scaffold built around accessibility, performance, token-driven styling, and clear extension points.

## Principles

- Semantic HTML first
- Token-driven visual decisions
- Ref-forwarding for composition
- CSS variables for theming
- Small, focused component APIs
- Storybook as the documentation and QA surface

## Local Development

```bash
npm install
npm run build:tokens
npm run dev
```
