# Kbd

Displays keyboard keys and shortcuts as styled key caps. Use a single key via children, or pass `keys` for a combination — each entry renders as its own cap with separators between.

Renders semantic `<kbd>` elements, so screen readers and assistive tech recognize it as keyboard input. Comes in `sm` (inline with text) and `md` sizes.
