# Modals

Modal provides an overlay dialog for focused tasks, confirmations, and longer in-context workflows.

## Anatomy

A Modal renders a dimmed overlay plus a centered dialog made of three stacked
regions. Most of the time you drive them through props — but the section
components (`ModalHeader`, `ModalBody`, `ModalFooter`) are exported for fully
custom layouts.

**Header** — built from the `title`, `description`, and close button.
Fixed at the top with a **divider below**; it stays put while the body scrolls.

**Body** — your `children`.
The flexible middle region; it **scrolls internally** when content exceeds the
modal's max height, so the header and footer stay visible.

**Footer** — the `footer` prop.
Pinned at the bottom with a **divider above**, laid out as a **flex row** for
actions.

The header and footer are optional — omit `title`/`footer` for a body-only modal.

```tsx
<Modal
  open={open}
  onOpenChange={setOpen}
  title="Delete project?"
  description="This action can't be undone."
  footer={
    <>
      <Button variant="secondary" onClick={() => setOpen(false)}>
        Cancel
      </Button>
      <Button variant="destructive" onClick={confirm}>
        Delete
      </Button>
    </>
  }
>
  Everything in this project will be permanently removed.
</Modal>
```

## API Reference

### `Modal`

**`open`** — `boolean` · required  
Controls whether the modal is visible.

**`onOpenChange`** — `(open: boolean) => void`  
Called when the modal should close — from the close button, overlay click, or Escape key.

**`title`** — `ReactNode`  
Heading text rendered in the header. Also serves as the dialog's accessible name. Use `aria-label` instead when you need a headingless modal.

**`description`** — `ReactNode`  
Secondary text rendered below the title in the header.

**`footer`** — `ReactNode`  
Content pinned at the bottom of the dialog, typically action buttons. Laid out as a flex row.

**`size`** — `'sm' | 'md' | 'lg'` · default `'md'`  
Controls the max-width of the dialog.

**`closeOnOverlayClick`** — `boolean` · default `true`  
Whether clicking the dimmed overlay closes the modal.

**`showCloseButton`** — `boolean` · default `true`  
Whether the × close button is shown in the header.

**`aria-label`** — `string`  
Accessible name for the dialog when `title` is not provided (e.g. a body-only modal with no visible heading).
