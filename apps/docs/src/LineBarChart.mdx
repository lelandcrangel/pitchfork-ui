# Line & Bar Charts

Pure SVG charts — no external dependencies. Both `LineChart` and `BarChart` accept the same `data` and `series` shape and render responsively inside their container.

```tsx
import { LineChart, BarChart } from '@pitchfork-ui/react';

const data = [
  { label: 'Jan', sessions: 420, users: 280 },
  { label: 'Feb', sessions: 380, users: 240 },
  // ...
];

const series = [
  { key: 'sessions', label: 'Sessions' },
  { key: 'users', label: 'Users' },
];
```
